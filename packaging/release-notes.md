# KUGOUPLAY 1.1

KUGOUPLAY 是搭配 Windows 版酷狗音乐使用的桌面播放器。本版本提供单文件便携程序 `KUGOUPLAY.exe`，内含运行所需的桥接服务和 WebView2。

- 液态玻璃桌面组件与可旋转的 3D 黑胶封面。
- 支持播放／暂停、上一曲、下一曲，以及歌曲信息、歌词和进度显示。
- 点击唱片即可调整玻璃、歌名、歌手和歌词颜色，支持渐变和透明底色。
- 更新应用图标和进程名称，新增四张效果图。

使用时请先安装 Windows 版酷狗音乐。若酷狗已经普通启动且没有所需调试接口，请先完全退出酷狗，组件会尝试重新启动并连接。首次启动需要解压运行文件；封面和歌词需要联网。进度条当前只显示进度，不支持拖动跳转。

本版本面向 Windows x64。液态玻璃效果与截图表现取决于系统、显卡和截图方式。
